30 秒上手 DSH

一条命令启动，三条命令装插件

01

启动 Harness

Node.js 环境下一行命令拉起 Web 界面

$ npx @deepseek-ai/dsh web
02

找到插件

在本站搜索或让智能助手推荐，进入插件 GitHub 主页

# 查看插件 README 获取安装名
03

安装使用

在 DSH 内用 /plugin 安装，或直接命令行安装

$ dsh plugin add <plugin>
